# 🌍 Urban Explorer - Mobile Tourism App

## 📱 Overview
Urban Explorer is an Android mobile application developed during an AWS internship that helps tourists explore cities through interactive features and gamification. The app combines AWS services with local tourism to create an engaging user experience.

## ⭐ Key Features
- 🔐 User authentication system
- 📍 Location-based exploration
- 📸 Image recognition for landmarks
- 🎯 Points-based reward system
- 🏛️ Historical sites discovery
- 🍽️ Local food spots exploration
- 📱 Interactive user interface
- ☁️ Cloud-based storage and processing

## 🛠️ Technology Stack
- **Frontend**: Android (Java)
- **Backend**: AWS Services
  - 🔐 Amazon Cognito (Authentication)
  - 🖼️ Amazon Rekognition (Image Recognition)
  - 💾 AWS Amplify (Backend Integration)
  - 🗄️ AWS DataStore (Data Management)
  - ☁️ Amazon S3 (Storage)
  - 📊 AWS AppSync (API Management)

## 🏗️ Architecture
- **Model-View-Controller (MVC)** architecture
- **AWS Amplify** framework integration
- **Offline-first** data synchronization
- **Real-time** updates and authentication
